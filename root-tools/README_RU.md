# Root-tools v1.0.1

Каталог релиза содержит точный APK Magisk Alpha и две GPL-утилиты, которые
использовались при настройке эталонного телефона:

- `Magisk-Alpha-e8a58776-30700.apk`;
- `Integrity-Box-v41.zip`;
- `PlayIntegrityFork-v18.zip`.

Integrity Box и PIF нельзя держать активными одновременно: оба используют id
`playintegrityfix`. Правильный порядок и минимальная конфигурация описаны в
`POST_INSTALL_ROOT_RU.md`.

Tricky Store не вложен: новые версии проекта закрыты, поэтому бинарник должен
загружаться с официальной страницы автора. Скрипты `download-tricky-store.sh`
и `download-tricky-store.ps1` скачивают публичный stable build 245 и сверяют
официальный SHA-256 до сохранения.

Публичный build 245 не объявляется эквивалентом закрытого `248-3b07ee3`, с
которым T‑Pay впервые заработал на эталонном телефоне. Выполните проверку и при
необходимости ручной резервный вариант из `POST_INSTALL_ROOT_RU.md`. И
установщик Integrity Box v41, и его Action вызывают сетевой updater, который
должен писать прямо в `/data/adb/tricky_store/keybox.xml`. До установки нужно
сделать backup и проверку внешнего attestation-state, а затем проверить журнал
и итоговый файл, не доверяя только экрану завершения.

При переходе с Integrity Box на PIF v18 ставьте PIF прямо поверх того же module
id, не удаляя Integrity Box отдельно. Именно этот установщик PIF может
скопировать старый `uninstall.sh` Integrity Box, который при будущем удалении
снесёт конфигурацию Tricky Store. В `POST_INSTALL_ROOT_RU.md` приведены
проверяемое по сигнатурам удаление этого скрипта и обязательная закрытая копия.

`keybox.xml`, fingerprint, Magisk DB, данные банковского приложения и
модифицированные APK Google намеренно не входят в релиз.
