Новый BOOT содержит Magisk Alpha e8a58776/30700 и правило сохранения TWRP.
Он прошит и проверен на физическом SM-N9750 HZE1. Подробности находятся в
обновлённой шапке темы. Также добавлено исправление входа по отпечатку T‑Банка
8.2.2: после recovery каталог [CODE]/sdcard/TWRP[/CODE] безопасно переносится в
[CODE]/sdcard/RecoveryBackups[/CODE]; данные банка очищать не нужно.

При переходе со старого v1.0.1 сначала установите/откройте Alpha из полного
архива GitHub-релиза и подтвердите root, затем удалите [B]только[/B] прежний
manager через карточку приложения Android либо командой
[CODE]adb uninstall com.topjohnwu.magisk[/CODE]. Для команды нужны актуальные
Platform Tools, временная USB-отладка и подтверждённый RSA-ключ компьютера. Не
выбирайте полное удаление Magisk/root. Если старый manager был скрыт под
случайным пакетом, точная процедура безопасной миграции дана в обновлённой
инструкции.
