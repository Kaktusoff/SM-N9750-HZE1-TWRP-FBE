# История изменений

## v1.0.1 — полностью заменён 2026-09-05

Существующий релиз v1.0.1 заменён на месте единым комплектом Alpha + TWRP +
банковский профиль. Новый релиз и новый тег не создавались. v1.0.0 снят с
поддержки и удаляется из загрузок.

- Официальный Magisk 30.7 заменён на проверенный на телефоне Magisk Alpha
  `e8a58776-alpha (30700)`: именно после этой замены T‑Pay стал доступен и
  принял карту.
- Добавлен безопасный переход на месте: после подтверждения Alpha-root
  удаляется только отдельный APK прежнего manager `com.topjohnwu.magisk`, в том
  числе описан случай старого скрытого случайного пакета. Полное удаление
  Magisk/root не запускается.
- Alpha ramdisk объединён с `overlay.d/twrp-survival.rc`, потерянным при
  повторном патче BOOT. Правило останавливает `vendor_flash_recovery` на
  `early-init` и сохраняет TWRP.
- Новый BOOT прошит на физический `SM-N9750`, прошёл обычную загрузку Android,
  проверку `su`, read-back SHA-256 и полный цикл Android → TWRP → Android.
- RECOVERY не пересобирался: это тот же проверенный lab13 FBE-бинарник, но с
  именем v1.0.1 и прежним SHA-256.
- Перепакованы Linux/Heimdall и Windows/Odin варианты без USERDATA/PIT.
- Сохранены защищённые режимы `--flash-no-wipe` для BOOT+RECOVERY и
  `--twrp-only-no-wipe` для одного RECOVERY на уже разблокированном точном
  HZE1. Первая разблокировка загрузчика Samsung по-прежнему всегда стирает
  данные.
- В релиз добавлены точный Alpha manager APK, Integrity Box v41 и PIF v18.
  Tricky Store скачивается с upstream и проверяется по SHA-256, а не
  перепубликуется как закрытый бинарник.
- Банковская инструкция переписана по фактическому рабочему состоянию:
  встроенный Zygisk + DenyList + PIF v18 + Tricky Store. Shamiko, Vector,
  Zygisk Next и HMA не являются частью default bank-first профиля.
- Добавлены проверенный шаг скрытия manager Magisk и точный набор Tricky Store
  targets, включая принудительный generate-certificate mode для GMS, T‑Банка
  и Key Attestation.
- Явно описано, что Integrity Box и PIF имеют один module id
  `playintegrityfix` и заменяют друг друга. Добавлена проверка журнала Integrity
  Box и итогового `/data/adb/tricky_store/keybox.xml`, а также ручной вариант с
  резервной копией, потому что Action не завершил это обновление на эталонном
  телефоне.
- Добавлены проверяемая резервная копия Tricky Store до установки/Action и
  fail-closed проверка внешнего OMK/TEE Simulator/persistent-key state: и
  установщик Integrity Box, и Action способны его переписать, но очистка при
  переходе не может безопасно восстановить.
- Описан безопасный переход на PIF v18 установкой прямо поверх Integrity Box и
  удаление унаследованного uninstall-скрипта, который при будущем удалении PIF
  мог бы снести keybox/targets Tricky Store.
- Возвращены и проверены запуском YouTube ReVanced Extended `20.51.39` и
  YouTube Music ReVanced Extended `9.15.51`; их Magisk-модули можно держать
  отключёнными, пока data-приложения установлены.
- Найден отдельный файловый триггер T‑Банка 8.2.2: даже пустой
  `/storage/emulated/0/TWRP` убирал пункт входа по отпечатку. После безопасного
  переноса каталога в `RecoveryBackups` без очистки данных банка одновременно
  подтверждены рабочие T‑Pay и биометрический вход.
- Добавлены ADB-помощники для Linux/macOS и Windows, которые останавливают
  только T‑Банк и переносят каталог TWRP под уникальным именем, не удаляя и не
  перезаписывая резервные копии. Описаны Platform Tools, USB-отладка/RSA и
  разовый запуск PowerShell без изменения системной политики.
- Удалена прежняя рекомендация очищать данные банка после изменения профиля:
  при рабочем T‑Pay это ненужно и может потребовать повторной активации карт.

## v1.0.0 — 2026-09-04 (снят с публикации)

Первый публичный релиз, полностью проверенный на физическом устройстве.

### Recovery и расшифровка FBE

- TWRP 3.7.1_12 собран из зафиксированных исходников Android 12.1 под точную
  геометрию recovery HZE1 и штатный аппаратный стек телефона.
- Реализован отсутствовавший двухэтапный Samsung/Qualcomm-процесс synthetic
  password:
  - HAT от пользовательского PIN/пароля открывает synthetic-password blob;
  - отдельно вычисляется credential `sp-gk-authentication`;
  - проверяется Gatekeeper handle synthetic password основного пользователя;
  - второй HAT сохраняется и проверяется по Secure User ID;
  - SID-совместимый HAT авторизует расшифровку CE-ключа через Keymaster.
- Добавлена совместимость с Android 12 KeyMint/Keymaster в HZE1.
- Удалён недоступный старый путь `keystore_auth`, при этом сохранены нужные HZE1
  службы `keystore2`, Gatekeeper, Keymaster и qseecomd.
- Добавлены recovery HIDL-зависимости для Qualcomm QSEECom.
- На реальном телефоне подтверждена расшифровка `/data` пользователя 0 штатным
  Android PIN/паролем.

### Обычная загрузка и сохранение TWRP

- Точный BOOT из работающей HZE1 обработан официальными скриптами Magisk 30.7.
- Root работает при обычной загрузке: `RECOVERYMODE=false`, `LEGACYSAR=true`,
  `PREINITDEVICE=cache`, `KEEPVERITY=true`, `KEEPFORCEENCRYPT=true`.
- Сохранены геометрия BOOT и встроенный vbmeta descriptor; Magisk устанавливает
  AVB flags 3 для разблокированного загрузчика.
- Добавлен `overlay.d/twrp-survival.rc`: он останавливает Samsung-службу
  `vendor_flash_recovery` на early-init без изменения `/vendor`.
- Подтверждены обычная загрузка Android, рабочий `su` и сохранение lab13 TWRP
  после загрузки системы.

### Проверка результата

- SHA-256 раздела BOOT, считанного обратно с телефона, совпадает с релизом.
- SHA-256 раздела RECOVERY после обычной загрузки Android совпадает с релизом.
- После Android TWRP снова загружен и сообщил версию lab13.
