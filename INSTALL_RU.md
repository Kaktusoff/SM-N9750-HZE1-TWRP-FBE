# Установка со стоковой HZE1

## 1. Перед началом

Инструкция предназначена только для `SM-N9750` на `N9750ZSU6HZE1`.
Разблокировка загрузчика выполняет factory reset и необратимо сжигает Knox.
Зарядите телефон, сохраните все данные и заранее скачайте полную стоковую HZE1
для аварийного возврата.

Проверенный способ прошивки — Heimdall. Odin-архив не публикуется, поскольку
финальная связка BOOT+RECOVERY через Odin на железе не проверялась.

## 2. Разблокировка загрузчика

Раздел можно пропустить, если Download Mode уже показывает разблокированный
загрузчик.

1. В Android включите параметры разработчика и **OEM-разблокировку**.
2. Полностью выключите телефон.
3. Зажмите обе клавиши громкости и подключите USB к компьютеру.
4. На экране Samsung выполните указанное долгое нажатие Volume Up и подтвердите
   разблокировку. Телефон сотрёт данные.
5. Пройдите первоначальную настройку Android, подключитесь к Интернету, снова
   включите параметры разработчика и убедитесь, что OEM-разблокировка уже
   активна.

Нельзя блокировать загрузчик при установленных custom BOOT или RECOVERY.

## 3. Проверка файлов

Установите Heimdall и распакуйте релиз. В каталоге с образами выполните:

```bash
sha256sum -c SHA256SUMS
```

Оба образа должны получить статус `OK`. Пока Android загружен, дополнительно
проверьте модель и прошивку:

```bash
adb shell getprop ro.product.model
adb shell getprop ro.build.version.incremental
```

Ожидаются `SM-N9750` и `N9750ZSU6HZE1`.

## 4. Выбор режима прошивки

Ни один из режимов ниже не форматирует и не прошивает `USERDATA`. Установка без
потери данных возможна только тогда, когда Download Mode уже показывает
разблокированный загрузчик. Первая разблокировка загрузчика Samsung всегда
выполняет factory reset; этот комплект не может отменить такое стирание.

Для постоянного TWRP и обычной загрузки Android с Magisk используйте:

```bash
./flash-heimdall.sh --flash-no-wipe
```

Команда прошивает только `BOOT` и `RECOVERY`; существующие данные Android на
точной базе HZE1 сохраняются. Старый параметр `--flash` остаётся псевдонимом
этого режима.

Чтобы установить только TWRP, не меняя `BOOT` и пользовательские данные:

```bash
./flash-heimdall.sh --twrp-only-no-wipe
```

Режим только RECOVERY удобен для проверки или доступа к уже зашифрованным
данным. Если BOOT остаётся полностью стоковым, Samsung может восстановить
стоковый recovery после следующей обычной загрузки Android. Для постоянного
TWRP используйте связанный режим BOOT+RECOVERY выше.

## 5. Прошивка и вход в TWRP

Переведите телефон в Download Mode, подключите USB и проверьте соединение:

```bash
heimdall detect
```

Запустите защищённый скрипт из комплекта:

```bash
./flash-heimdall.sh --flash-no-wipe
```

Либо выполните точную команду вручную:

```bash
heimdall flash \
  --BOOT SM-N9750-HZE1-Magisk-v30.7-BOOT-v1.0.0.img \
  --RECOVERY SM-N9750-HZE1-TWRP-3.7.1_12-FBE-v1.0.0.img \
  --no-reboot
```

После сообщения об успехе удерживайте Volume Down + Side/Power до погасания
экрана, затем сразу переключитесь на Volume Up + Side/Power, не отключая USB.
Отпустите клавиши после появления TWRP.

## 6. Первый запуск TWRP

1. Проверьте версию `3.7.1_12-HZE1-FBE-lab-13`.
2. Введите тот же PIN или пароль, которым разблокируется Android.
3. Убедитесь, что внутренняя память показывает нормальные имена каталогов и
   размеры файлов.
4. Не форматируйте `/data`. Ошибка расшифровки на точной HZE1 — повод снять
   журнал, а не стирать данные.
5. Выберите **Reboot > System**.

Android должен загрузиться обычным нажатием Power. Модифицированный BOOT на
этапе early-init останавливает Samsung-службу `vendor_flash_recovery`, поэтому
стоковый recovery больше не восстанавливается поверх TWRP.

Если выбран режим только RECOVERY, пункт **Reboot > System** не добавит root, а
стоковый BOOT может восстановить стоковый recovery. Следующие шаги относятся к
связанному режиму BOOT+RECOVERY.

## 7. Приложение Magisk

Скачайте официальный Magisk 30.7 со
[страницы релиза](https://github.com/topjohnwu/Magisk/releases/tag/v30.7):

```bash
adb install Magisk-v30.7.apk
```

В приложении должны отображаться Magisk `30.7` и рабочий root. Для маскировки
самого менеджера откройте настройки Magisk, выберите **Скрытие приложения
Magisk**, оставьте нейтральное имя `Settings` либо задайте своё и дождитесь
создания случайного имени пакета.

## 8. Вход в TWRP в дальнейшем

Выключите телефон, оставьте USB подключённым и удерживайте Volume Up +
Side/Power до появления TWRP.

## 9. Возврат на сток

Самый надёжный откат — прошивка полной точной стоковой
`N9750ZSU6HZE1`. Прошивка только стокового BOOT уберёт root, но при следующей
загрузке стоковая vendor-служба также восстановит стоковый recovery.

Блокировать загрузчик разрешается только после полного возврата всех разделов
на сток и успешной проверки загрузки. Повторная блокировка снова стирает данные,
а Knox уже не восстановится.
